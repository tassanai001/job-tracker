# Job Tracker with Notification System

Track your job applications, receive follow-up reminders via email and in-app (real-time), and stay organized during your job search.

## Features

- JWT-based user authentication
- Add, update, delete job applications
- Set follow-up reminders
- Email & real-time (WebSocket) notifications
- Modular architecture using Dependency Inversion Principle (DIP)
- MongoDB storage

## Tech Stack

- Node.js + Express
- MongoDB + Mongoose
- Socket.IO for WebSocket communication
- Nodemailer for email notifications
- Jest for unit testing
